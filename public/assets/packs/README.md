# Asset packs (not committed)

Put licensed tilesets and character packs here, one folder per pack, e.g.
`public/assets/packs/office-tiles/`. This folder is gitignored (except this
README) so paid assets never end up in the repo.

After adding a pack:
1. Point `config/assets.json` at it.
2. Add its author, URL and license to `ATTRIBUTIONS.md`.
